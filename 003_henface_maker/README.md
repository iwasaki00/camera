# 変顔メーカー

React + Vite + TypeScript + MediaPipe Face Landmarker を使った、iPhone Safari 向けの変顔アプリです。

## v0.6.2-debug-results：瞬きキャッチの確認表示と結果画面

URLの末尾に `?debug=1` を付けて「瞬きキャッチ」を開くと、開発表示セレクトが表示されます。
通常レイアウトの「処理時間を表示（開発用）」を有効にしてからゲームへ入る方法もあります。

- `normal`：通常のゲーム表示。
- `parts-only`：暗色背景に実際のフェザー付き抽出パーツだけを表示。開始前は4パーツ、プレイ中は落下中・固定済みパーツを表示します。
- `original`：元映像のみ。
- `blank-face`：消去・平滑化後のみ。パーツの落下や貼り戻しはしません。
- `bounds`：元映像上に抽出範囲とラベルを表示。右目は赤、左目は青、鼻は紫、口は緑。枠は落下パーツと同じ余白込みの切り出し範囲です。

元映像・消去後・範囲表示への切替はゲーム進行をリセットします。「カメラ確認」で開始し、進行なしで確認できます。
`parts-only` は「ゲームスタート」から遊べます。「デバッグOFF」で通常表示へ戻ります。
のっぺらぼう化アルゴリズムはv0.6.1のまま維持しています。

完成時は通常の完成顔を専用Canvasに一度描画してPNG表示を固定します。ライブの取り込み・検出・描画を止め、
完成顔を比率維持で表示し、その下の不透明カードに完成・評価・正解度・変顔度と再挑戦・保存・通常へ戻る操作を配置します。
保存も固定Canvasを使います。最後の固定演出中に顔を見失った場合は、その直前に確保した完成顔を使用します。
再挑戦・通常モードへの復帰では固定画像を解除します。カメラストリーム自体は再挑戦のため維持します。

`npm test`、`npm run typecheck`、`npm run build` に加え、開発サーバー上の
`/tests/blink-drop-rendering.html` と `/tests/blink-drop-results.html` で描画と390×844の結果UIを確認できます。
PCブラウザの合成顔による検証です。iPhone Safari実機の瞬き操作、実顔の消去品質、保存操作は未確認です。

## 機能

- 前面カメラ起動
- 顔ランドマーク検出
- `眉 / 目 / 耳 / 頬 / 鼻 / 口 / 頭 / 顎` のパーツ変形
- 画面下部のタブとスライダーで調整
- スクリーンショット保存
- リセット
- ランダム変顔
- 3 つのプリセット
  - `びっくり顔`
  - `宇宙人顔`
  - `おじさん顔`
- `🎲 ランダム事故`
  - `軽い事故`
  - `大事故`
  - `宇宙人事故`
  - `ホラー事故`
  - `ギャグ事故`
  - `イケメン事故`
- 0.5 秒のガチャ演出
- 変顔診断結果表示

## v0.2.0-feather — 顔パーツ変形の境界改善

- 元のカメラフレームを左右反転して専用canvasへ一度取り込み、鼻 → 口 → 目 → 眉の順で合成します。
- 各パーツは常に元画像を参照します。出力canvasの再利用とパーツごとの矩形復元を廃止しました。
- 楕円のフェザーマスクで外周アルファを滑らかに減衰させます。縮小・移動時にも、ぼかした矩形で消す処理は使いません。
- 局所切り出し内部の12×12格子をCanvas 2Dで補間し、中心の拡大縮小を外周では元の位置へ戻します。本格的な顔全体メッシュではありません。
- 高倍率ほど領域を広げますが、隣接する顔パーツまで巻き込まないようランドマーク間距離で上限を設けます。極端な縦横・全体倍率の積は0.35〜2.8に制限します。
- タブ、スライダーの方向・範囲、プリセット、ランダム、保存、MediaPipe取得方法は維持しています。合成後の描画型エフェクト用コールバックも用意しました。
- このチェックアウトには白目・つながり眉の専用実装が存在しません。その機能自体の互換性は未確認です。

主要実装は src/featureRenderer.ts。領域抽出、スライダー変換、影響範囲、フェザーマスク、変形バックエンド、フレーム合成を分離しています。
TransformOptions は中心、横/縦/全体倍率、楕円影響半径、フェザー幅、中心重み、移動量、濃さを保持します。
将来は transformFeatureRegion の内部だけを顔メッシュやGPU描画へ置換できます。

### 負荷調整

RENDER_SETTINGS で長辺上限（初期960px）、patchResolution（0.25〜1）、patchGrid（8〜24、初期12）を変更できます。
作業canvasを再利用し、マスクは最大24件・各辺512pxまでキャッシュします。
同じカメラ時刻かつ同じ設定なら再描画・再検出を省略し、設定変更時は保持したフレームに即時反映します。
新しい依存ライブラリはありません。Viteの相対baseとGitHub Pages構成を維持しています。

### 検証

- npm run typecheck
- npm run build
- npm run dev 後、/tests/rendering.html を開く（カメラ許可不要）。全項目PASSを確認。
- 既存distに書込権限がない環境では、npm run build -- --outDir build-check で独立した本番ビルドを検証可能です。

合成画像で元ソース不変、リセット一致、累積なし、マスクの透明化、複数パーツ、描画オーバーレイ、未検出、画面端・極端倍率を検証しました。
Chromeで480×640の強い同時変形を約7.2ms/frameで描画しました（顔検出を含まない参考値）。
iPhone Safari実機、実顔、眼鏡、弱い照明・横顔の品質と総フレーム時間は別途確認が必要です。
切り出し方式なので、強い同時変形では重複領域の優先順による不連続や眼鏡フレームの曲がりが残り得ます。

## v0.3.0-layouts — UI・レイアウト切替・全パーツランダム

### レイアウト

ヘッダーのレイアウト選択で切り替えます。初期値compact。選択はlocalStorageに保存し、保存が拒否される環境でも動作します。
レイアウトだけを変えてもカメラcanvasや変形パラメータを再生成しません。

| 表示 | 常時表示 | 詳細 |
| --- | --- | --- |
| standard | 上に映像、下にタブ・大きさ・距離/縦・横・4操作ボタン | 濃さ |
| compact | 映像、タブ・大きさ・距離/縦・4操作ボタン | 横・濃さ |
| edge-controls | 大きめの映像、左右端の半透明4操作ボタン、タブ・大きさ | 距離/縦・横・濃さ |

眉・目は距離、鼻・口は縦横を調整できます。主要ボタンとレイアウト選択は折りたたみに入れていません。
プリセット・従来のランダム事故・補助情報・バージョンは「プリセット・その他」にまとめました。
写真保存はカメラ起動後に利用できます。カメラ停止ボタンも追加しました。
画面高に合わせたプレビュー、safe-area余白、44px以上のボタン・選択メニューを使用します。
詳細を開いた時や横画面・文字拡大では必要な分だけスクロールできます。

### ランダム

選択パーツと全パーツが同じ強度設定を使います。全パーツの対象は眉・目・鼻・口のみです。
対象外パーツは維持し、眉・目の隠れた縦横倍率は1へ戻します。生成値はスライダー刻みに合わせます。

| 強度 | 大きさ | 縦横の振幅 | 距離の振幅 | 濃さの振幅 |
| --- | --- | --- | --- | --- |
| weak | 0.90〜1.15 | ±0.10 | ±0.04 | ±0.10 |
| normal | 0.75〜1.40 | ±0.18 | ±0.10 | ±0.18 |
| wild | 0.65〜1.65 | ±0.30 | ±0.18 | ±0.28 |

縦横・濃さは0.05刻みへの丸めで端が最大0.025変わります。距離は0.01刻み。
増幅後の全体倍率×縦横倍率が0.4〜2.4を外れる場合は該当軸を1へ戻し、倍率の重なりを抑えます。

### パフォーマンスと互換性

- requestAnimationFrameを維持し、カメラ処理を最大30fpsへ制限。設定変更時は次のRAFで反映します。
- 同じフレーム・同じ設定の再描画省略、元画像専用canvas、フェザーマスクキャッシュは継続。
- 顔検出状態が変わった時だけステータス・案内文を更新します。
- 内部出力長辺を960pxから720pxへ変更し、ピクセル数を最大約44%削減。保存画像もこのcanvas解像度です。
- MediaPipe取得方式、v0.2.0-featherの変形アルゴリズム、元画像参照方式、相対baseは維持。追加依存なし。

## v0.4.0-faceplay — 高速化・顔配置・特殊効果

### 計測・更新頻度

「品質・ランダム設定・その他」で品質と開発用計測表示を選べます。URLに `?debug=1` を付けても表示できます。
表示は実際に出力したフレーム数から求めたFPS、検出更新時の平均時間、フレーム当たりの変形・合成・総処理時間です。
1秒ごとに計測欄のDOMだけを更新し、計測のためにReact全体を再描画しません。
Canvas時間はCPU側の描画呼出し時間で、GPU完了時間ではありません。合成にはカメラ取り込み・ベース描画・パーツ貼り戻し・眉描画を含みます。

| 品質 | 出力長辺上限 | 局所格子 | 局所解像度 | 通常検出間隔 | 描画目標 |
| --- | --- | --- | --- | --- | --- |
| speed | 540px | 8×8 | 0.8 | 120ms | 24fps |
| balanced | 720px | 10×10 | 1 | 90ms | 30fps |
| quality | 960px | 14×14 | 1 | 65ms | 30fps |
| auto（初期値） | balanced / speed を自動選択 | 同左 | 同左 | 同左 | 同左 |

顔検出と描画を分離し、検出間のランドマークは40ms時定数の平滑化で追従します。
顔を見失ったら解除し、顔が大きく飛んだ場合は古い位置を引きずらないよう追跡を再初期化します。
速い移動を検出した後400msは、検出間隔を最大65msへ短縮して追従を優先します。
描画の時刻を繰り越して、60Hz RAFでも24fps設定が20fpsに丸められる問題を避けています。
カメラには最大30fpsを要求します。目標FPSは実機性能・撮影フレームレートによって変わり、保証値ではありません。

autoは処理負荷が高い状態が2秒続いた時にspeedへ切り替え、軽い状態が5秒続いた時にbalancedへ戻します。
内部解像度を変えてもランドマークは正規化座標のまま扱い、顔検出方式とモデルは維持しています。
保存画像も選択品質の出力解像度になります。

### 描画の無駄削減

- 全効果が標準なら領域抽出・格子生成を省略。濃さだけの変更では格子変形を行いません。
- 元画像を局所canvasへ取り込み、変形がない格子はそのまま使います。
- 局所canvasは32px単位のサイズで最大12個再利用。フェザーマスクは従来通り最大24個再利用します。
- 領域計算はランドマーク位置・フレームサイズをキーに直近の結果を再利用します。判定は0.5px単位です。
- 加工済み画像のソース再利用は引き続き禁止。下顔面、鼻、口、目、眉をすべて元カメラ画像から合成し、つながり眉を最後に描画します。

### 追加エフェクト

配置は中央集合、外側拡散、上下圧縮、上下拡張、左右接近、左右分離、上寄せ、下寄せの8種類。
個別倍率とは別の位置オフセットとして合成し、強度と横・縦の重みを持ちます。移動は各局所領域半径の28%以内へ制限します。
配置の横・縦重みは詳細表示で個別調整できます。

特殊は極太眉、つながり眉、寄り目、潰れ鼻、歪み口、下顔面拡大、上下面アンバランスの7種類。
極太眉は眉の縦倍率と濃さ、つながり眉は変形後の眉位置をつなぐ描画、寄り目は独立した位置調整です。
潰れ鼻は縦縮小・横拡大、歪み口は局所的な傾斜と中心移動を使います。
下顔面は口〜顎の楕円領域の変形で、負の値では細化します。アンバランスは上部を縮め、下部を膨らませます。
各効果は選択を変えても保持され、併用できます。個別の解除ボタンと全部リセットで解除可能です。

### プリセット・ランダム・UI

- 極太眉モンスター：極太・つながり眉、寄り目、潰れ鼻、歪み口、下顔面拡大。
- 宇宙人顔：中央集合、寄り目、やや大きい目、下顔面細化。
- 魚顔：外側拡散、おちょぼ口、下顔面拡大。
- 悪役顔：強い眉、鼻の縦倍率と軽い潰れ鼻、歪み口。

プリセットはパーツ・配置・特殊を一括設定し、その後の手動調整が可能です。
全パーツランダムのweak / normal / wildを維持し、詳細のチェックで配置・特殊も含められます。初期値は従来のパーツのみです。
特殊ランダムは疎な組み合わせとし、中央集合＋寄り目や下顔面拡大＋アンバランスの強度の重なりを抑えます。

UIはパーツ / 配置 / 特殊 / プリセットの4カテゴリ。特殊は種類選択＋単一スライダーで操作します。
3レイアウト、レイアウト保存、現在値の保持、選択パーツランダム、各リセット、写真保存を維持しています。
映像の高さはカテゴリで調整し、使わないスライダーの場所をカメラへ戻します。
