# 変顔メーカー

React + Vite + TypeScript + MediaPipe Face Landmarker を使った、iPhone Safari 向けの変顔アプリです。

## 機能

- 前面カメラ起動
- 顔ランドマーク検出
- `眉 / 目 / 耳 / 頬 / 鼻 / 口 / 頭 / 顎` のパーツ変形
- 画面下部のタブとスライダーで調整
- スクリーンショット保存
- リセット
- ランダム変顔
- 3 つのプリセット
  - `びっくり顔`
  - `宇宙人顔`
  - `おじさん顔`
- `🎲 ランダム事故`
  - `軽い事故`
  - `大事故`
  - `宇宙人事故`
  - `ホラー事故`
  - `ギャグ事故`
  - `イケメン事故`
- 0.5 秒のガチャ演出
- 変顔診断結果表示

## 使い方

```bash
cd 003_henface_maker
npm install
npm run dev
```

## build

```bash
npm run build
```

`dist/` が出力されます。

## GitHub Pages

`vite.config.ts` で `base: "./"` を指定しているので、GitHub Pages に載せやすい構成です。

手順例:

1. `cd 003_henface_maker`
2. `npm install`
3. `npm run build`
4. `dist/` を Pages 用に公開する、または GitHub Actions で deploy する

既存の `002_face_effect` と同じように workflow を分ければ、別アプリとして公開できます。

## 注意

- iPhone Safari では HTTPS 環境で開いてください
- カメラ許可が必要です
- 最初は 1 人の顔のみ対応です
- 完全なメッシュ変形ではなく、パーツ単位の簡易変形です

## v0.2.0-feather — 顔パーツ変形の境界改善

- 元のカメラフレームを左右反転して専用canvasへ一度取り込み、鼻 → 口 → 目 → 眉の順で合成します。
- 各パーツは常に元画像を参照します。出力canvasの再利用とパーツごとの矩形復元を廃止しました。
- 楕円のフェザーマスクで外周アルファを滑らかに減衰させます。縮小・移動時にも、ぼかした矩形で消す処理は使いません。
- 局所切り出し内部の12×12格子をCanvas 2Dで補間し、中心の拡大縮小を外周では元の位置へ戻します。本格的な顔全体メッシュではありません。
- 高倍率ほど領域を広げますが、隣接する顔パーツまで巻き込まないようランドマーク間距離で上限を設けます。極端な縦横・全体倍率の積は0.35〜2.8に制限します。
- タブ、スライダーの方向・範囲、プリセット、ランダム、保存、MediaPipe取得方法は維持しています。合成後の描画型エフェクト用コールバックも用意しました。
- このチェックアウトには白目・つながり眉の専用実装が存在しません。その機能自体の互換性は未確認です。

主要実装は src/featureRenderer.ts。領域抽出、スライダー変換、影響範囲、フェザーマスク、変形バックエンド、フレーム合成を分離しています。
TransformOptions は中心、横/縦/全体倍率、楕円影響半径、フェザー幅、中心重み、移動量、濃さを保持します。
将来は transformFeatureRegion の内部だけを顔メッシュやGPU描画へ置換できます。

### 負荷調整

RENDER_SETTINGS で長辺上限（初期960px）、patchResolution（0.25〜1）、patchGrid（8〜24、初期12）を変更できます。
作業canvasを再利用し、マスクは最大24件・各辺512pxまでキャッシュします。
同じカメラ時刻かつ同じ設定なら再描画・再検出を省略し、設定変更時は保持したフレームに即時反映します。
新しい依存ライブラリはありません。Viteの相対baseとGitHub Pages構成を維持しています。

### 検証

- npm run typecheck
- npm run build
- npm run dev 後、/tests/rendering.html を開く（カメラ許可不要）。全項目PASSを確認。
- 既存distに書込権限がない環境では、npm run build -- --outDir build-check で独立した本番ビルドを検証可能です。

合成画像で元ソース不変、リセット一致、累積なし、マスクの透明化、複数パーツ、描画オーバーレイ、未検出、画面端・極端倍率を検証しました。
Chromeで480×640の強い同時変形を約7.2ms/frameで描画しました（顔検出を含まない参考値）。
iPhone Safari実機、実顔、眼鏡、弱い照明・横顔の品質と総フレーム時間は別途確認が必要です。
切り出し方式なので、強い同時変形では重複領域の優先順による不連続や眼鏡フレームの曲がりが残り得ます。

## v0.3.0-layouts — UI・レイアウト切替・全パーツランダム

### レイアウト

ヘッダーのレイアウト選択で切り替えます。初期値compact。選択はlocalStorageに保存し、保存が拒否される環境でも動作します。
レイアウトだけを変えてもカメラcanvasや変形パラメータを再生成しません。

| 表示 | 常時表示 | 詳細 |
| --- | --- | --- |
| standard | 上に映像、下にタブ・大きさ・距離/縦・横・4操作ボタン | 濃さ |
| compact | 映像、タブ・大きさ・距離/縦・4操作ボタン | 横・濃さ |
| edge-controls | 大きめの映像、左右端の半透明4操作ボタン、タブ・大きさ | 距離/縦・横・濃さ |

眉・目は距離、鼻・口は縦横を調整できます。主要ボタンとレイアウト選択は折りたたみに入れていません。
プリセット・従来のランダム事故・補助情報・バージョンは「プリセット・その他」にまとめました。
写真保存はカメラ起動後に利用できます。カメラ停止ボタンも追加しました。
画面高に合わせたプレビュー、safe-area余白、44px以上のボタン・選択メニューを使用します。
詳細を開いた時や横画面・文字拡大では必要な分だけスクロールできます。

### ランダム

選択パーツと全パーツが同じ強度設定を使います。全パーツの対象は眉・目・鼻・口のみです。
対象外パーツは維持し、眉・目の隠れた縦横倍率は1へ戻します。生成値はスライダー刻みに合わせます。

| 強度 | 大きさ | 縦横の振幅 | 距離の振幅 | 濃さの振幅 |
| --- | --- | --- | --- | --- |
| weak | 0.90〜1.15 | ±0.10 | ±0.04 | ±0.10 |
| normal | 0.75〜1.40 | ±0.18 | ±0.10 | ±0.18 |
| wild | 0.65〜1.65 | ±0.30 | ±0.18 | ±0.28 |

縦横・濃さは0.05刻みへの丸めで端が最大0.025変わります。距離は0.01刻み。
増幅後の全体倍率×縦横倍率が0.4〜2.4を外れる場合は該当軸を1へ戻し、倍率の重なりを抑えます。

### パフォーマンスと互換性

- requestAnimationFrameを維持し、カメラ処理を最大30fpsへ制限。設定変更時は次のRAFで反映します。
- 同じフレーム・同じ設定の再描画省略、元画像専用canvas、フェザーマスクキャッシュは継続。
- 顔検出状態が変わった時だけステータス・案内文を更新します。
- 内部出力長辺を960pxから720pxへ変更し、ピクセル数を最大約44%削減。保存画像もこのcanvas解像度です。
- MediaPipe取得方式、v0.2.0-featherの変形アルゴリズム、元画像参照方式、相対baseは維持。追加依存なし。
