# 変顔メーカー

React + Vite + TypeScript + MediaPipe Face Landmarker を使った、iPhone Safari 向けの変顔アプリです。

## v0.9.1-natural-face-compositing — 肌補間とパーツ境界の調整

カオストップ！の描画だけを改善しました。表情検出、4ターン、難易度の軌道、FREE/CHALLENGE採点、カウントダウン、完成後の顔ローカル追従は変更していません。
通常変顔メーカーの描画・写真保存・レイアウト・ランダムも変更していません。ゲームの写真保存は廃止済みのままです。

### 原因調査と補間

元のカメラフレームを顔の傾きに合わせて整列し、6領域を求め、肌の再構成、パーツ合成、顔の傾きの復元という既存の流れを維持します。
パーツは常に元画像から抽出します。貼り付け済みパーツを別パーツの補間・色補正に再利用しません。

コードで確認した品質上の制約は、旧フィールドが4つの平均色を固定の縦横勾配で混合すること、サンプルの実際の位置・肌の質感・時間安定性を使わないことです。
消去領域ごとに同じフィールドを切り出し直す際の拡縮と丸め、中央の追加ぼかしも、局所的な継ぎ目や平板な見え方の要因になります。
軽量抽出にはランドマーク輪郭が切り出し枠の外へ出る場合があり、外周の透明化が途中で切れる可能性も確認しました。
実機で報告されたすべての縦筋がこれらの原因と断定できるわけではありません。実顔の検証は未実施です。

- `skinReconstruction.ts`：額3点、こめかみ2点、頬4点、顎2点を候補に、最大11点から4×4画素ずつ取得します。四隅を顔輪郭内に収め、6パーツの矩形と眼鏡余白を避けます。カメラの回転後に透明領域へ入る候補も除外します。
- 暗部・透明・不適切な色・中央値から大きく離れた明るさを除外し、少なくとも3点を使用します。眼鏡や髪を厳密に物体検出する方式ではありません。安全な候補を得られない場合は既存補間へフォールバックします。
- 実際のサンプル位置を使い、弱い正則化をかけた照明平面＋距離加重の残差補間で48×64の共通肌フィールドを作ります。1列の引き伸ばしはありません。実サンプルの輝度残差を12%、最大±1.5RGBだけ加え、ランダムなノイズは追加しません。
- 候補位置は顔ローカル座標で平滑化し、色は時定数160msで補間します。90ms未満ではフィールドを再利用し、顔の位置・傾き・倍率へは毎フレーム追従します。450ms超の中断や時計の巻き戻りでは色履歴をリセットします。
- 6つの消去マスクを合成した後、共通フィールドを1回貼り戻します。内部は不透明、外側だけ12段階で透明化します。フェザー幅は眼間距離の7%（1.5〜22px）。新方式では顔中央の追加ぼかしを使いません。
- 消去用の2つのCanvasは顔の周辺だけを処理し、8px単位の寸法で再利用します。肌のImageDataは48×64の1枚を再利用、読み戻しは最大176画素・1回/90msです。距離重みは最大4件、描画マスク・パッチにも既存の上限があります。

### 落下パーツとcompleted

目・眉は引き続き別の輪郭・画像で、同じ落下量、回転、倍率で移動・固定します。眼鏡余白スライダーも維持します。
playing/fixingの形状と軽量合成は流用し、輪郭実寸と外周フェザーを収める余白を追加しました。
鼻・口の外周が矩形の切り出し枠で切れないようにしています。

completedだけ、既存の24段階外向きフェザー・境界リング処理を使用します。
フェザーは眼間距離に比例し、目5.5%、眉3.8%、鼻5%、口4.5%（各1.5〜22px）。
ぼかしと色補正のリングは輪郭の外側に限定しました。瞳・眉毛・唇・眼鏡を含む輪郭内部を色補正しません。
周辺肌のRGB差を28%、最大±12、彩度差を8%だけ補正し、そのリングを28%混合します。
色読み戻しは従来どおり16画素/パーツ・120ms間隔、補正履歴も平滑化します。顔外の貼り付け先では色補正を省略します。

## v0.9.0-final-polish-part-blend — completedのパーツ境界仕上げ

ゲームの `completed`・通常表示だけに高品質ブレンドを追加しました。
playing / fixing / countdown / paused、parts-only / boundsなどの確認表示は従来の軽量描画を維持します。
FREEとCHALLENGEで同じ仕上げを使用します。ルール・表情検出・落下・採点・ライブ追従・通常変顔メーカーは変更していません。
ゲームの写真保存は廃止済みのままで、通常モードの写真保存は維持しています。

### completed専用処理

- 元のランドマーク輪郭の不透明な内側を保持。輪郭の実寸から切り出し枠を広げ、マスクが矩形枠で切れない余白を確保します。
- 目は眼鏡レンズ余白を含む丸い輪郭、眉は細長い眉ランドマークの曲線、鼻は鼻筋〜小鼻〜鼻先、口は唇〜口角の既存輪郭を使います。
- 外周フェザーは3〜8px。旧4段階のストロークから24段階の外向き透明化にし、内側を薄くしません。眉の上下、鼻の左右、口の上下にも余白を確保します。
- 輪郭内側2px〜外側フェザー部分だけに、半解像度のコピーを28%混合して局所平滑化します。瞳・眉毛・鼻・唇の中心はこの処理を通しません。
- 周辺の肌色を元画像と貼り付け先から比較。貼り付け先はパーツを合成する前ののっぺらぼう画像を参照し、別パーツの色を再利用しません。
- 色差を22%・RGB差最大±12に抑え、彩度差も10%だけ寄せます。どちらも境界リング内だけで、リング混合率28%がさらにかかります。
- 色サンプルの四隅が顔内にあること、元画像の他パーツを避けること、透明・極端な暗部を使わないことを確認します。肌色を取得できない場合は色補正を省略します。
- 読み戻しは16画素だけ、120ms間隔。補正量も平滑化します。マスク・パッチ・リング・低解像度バッファは上限付きキャッシュで再利用します。

定数は `src/game/completedBlend.ts` の `COMPLETED_BLEND`、パーツ別フェザー量は `completedFeather` にあります。
`createBlinkDropRenderer({ completedPolish: false })` は比較テスト用に旧completed合成を選べます。
通常のアプリは追加オプションなしでcompleted仕上げを使用します。利用者向けUIは追加していません。
新しいライブラリ・Canvas filter・全画面ImageData加工・毎フレームのReact state更新はありません。

### 関連検証

- `tests/completed-blend.html`：新旧比較、中心不透明・四隅透明、境界リングのみ作用、6パーツ中心色保持、軽量フェーズのピクセル一致、FREE/CHALLENGE、固定位置・個別回転・倍率、顔移動・回転・距離、色サンプル間引き、安定フレームでCanvas再生成なし。

- 型チェック・本番ビルド成功。既存全件回帰・全画面開閉テストは実施していません。

iPhone Safari実機のFPS/発熱、実顔・眼鏡の反射・肌色・照明変化、近接したパーツの境界は未確認です。

## v0.8.0-face-challenge — カオストップ！

ゲームの正式名称は「カオストップ！」、サブタイトルは「表情で止めて、変顔を完成させよう！」です。
画面タイトル・入口・開始・完成表示を統一しました。内部識別子・ファイル名・localStorageキーは維持しています。

開始前にFREE（従来のフリーゲーム）またはCHALLENGE（お題に合わせるゲーム）を選びます。
難易度5段階と瞬き・見開き・開口・タップは共通です。操作設定は折りたたみで確認・変更でき、
モード・お題・難易度は開始時に確定します。完成後の「もう一回」は同じ条件で得点を初期化して再挑戦、
「モード選択へ戻る」はカメラを維持して設定画面へ戻り、「通常モードへ戻る」は変顔メーカーへ戻ります。

| お題 | 目標 | 落下周期内の目標時点（右目・左目・鼻・口） |
| --- | --- | --- |
| CH-01 ぴったり顔 | 本来のパーツ位置 | 0.75 / 0.75 / 0.75 / 0.75 |
| CH-02 おでこ目 | 両目と眉を上へ | 0.50 / 0.50 / 0.75 / 0.75 |
| CH-03 口が上すぎ！ | 口だけを上へ | 0.75 / 0.75 / 0.75 / 0.50 |
| CH-04 バラバラ顔 | 4種類の異なる高さ | 0.45 / 0.85 / 0.65 / 0.55 |
| CH-05 カオス顔 | 難易度に応じて位置・回転・倍率 | 0.625 / 0.875 / 0.68 / 0.82 |

目標は既存 `fallingStateAt` に難易度と上記の時点を渡して生成します。
縦・横・回転・倍率を別々に抽選しないため、同時に到達不可能な組み合わせを作りません。
落下軌道・周期・4ターン・目と眉の同時固定は変更していません。
CH-01の「本来位置」はパーツ中心の位置です。MONSTERの軌道上にはその位置で回転が残るため、
CH-01〜04は角度・倍率を採点対象にせず、完全な無回転・等倍を要求しません。

### ガイドと採点

現在のパーツと眉の輪郭を、控えめな半透明の点線と中心マーカーで示します。
顔の中心・目間距離・回転から顔ローカル座標を算出し、移動・傾き・距離変化に追従します。
ガイドは再利用する専用の透明Canvasへ描画し、写真保存の合成Canvasへは描きません。
顔未検出時はガイドを消去、完成・退出・カメラ停止時は即時消去します。

各パーツを固定した瞬間に目標との差を顔ローカル座標で比較し、0〜100点を保存します。
EASY / NORMAL / HARDは縦位置のみ、CHAOSとMONSTERは横位置も採点します。
MONSTERのCH-05のみ角度・倍率も採点します。重みは縦0.70・横0.15・角度0.10・倍率0.05で、
使用する項目の重み合計で正規化します。誤差の基準は縦2落下高さ単位・横顔幅0.20・角度45度・倍率差0.4。
定数は `src/game/faceChallenge.ts` にまとめています。FREEの正解度・変顔度計算は変更していません。
4パーツの平均を総合スコアとし、PERFECT（95〜100）、GREAT（80〜94）、GOOD（60〜79）、
CLOSE（40〜59）、MISS（0〜39）で評価します。固定時に個別評価、完成時にお題・総合・個別得点を表示します。
完成映像は従来どおりライブで、写真保存は押した瞬間の合成CanvasのPNGを使用します。

### 検証

## v0.6.5-blink-stability-blend — カウントダウン・連続瞬き・境界改善

### 原因と変更

旧HUDは文字列の「3」を固定表示しており、3秒のゲーム開始タイマーと残秒表示が同期していませんでした。
今回からセッションに開始時刻を持たせ、`performance.now()` の差から3→2→1を計算します。
同じ期限でplayingへ遷移し、最初の300msはSTART!を表示します。HUDだけを80ms間隔で更新し、タイマーを解除します。
一時停止はcountdown/playing/fixingに対応し、再開時に停止時間分だけ期限をずらします。
背景へ移った場合は一時停止し、戻った後は「再開」で続行します。背景中に開始した場合も停止状態へ移します。

旧瞬き判定には、最後の開眼から350msを超えると閉眼を受け付けない条件と、550msのクールダウン後に再開眼を確認し直す条件がありました。
旧版と同じ4回分の合成時系列で、ゆっくり閉じる例は旧0回→新4回、早く再開眼する例は旧2回→新4回を確認しました。
これはコード上の再現原因です。実機の眼鏡反射・短い閉眼の取り逃がしがすべて解消したとは確認していません。

判定器はOPEN / CLOSING / CLOSED / WAIT_REOPEN / COOLDOWNの状態機械です。
閉眼で1イベントだけ発行し、両目の2標本の再開眼を確認してから再アームします。
再開眼は240msのクールダウン中にも記憶し、期限後に余分な再開眼確認を要求しません。
ゲームのfixing中も開眼確認を継続し、判定器がreadyになってから次ターンへ進みます。
countdown/fixing/paused/completedでは確定イベントを抑止します。開始前に開眼確認が済んでいればSTART!でその状態を引き継ぎます。

左右独立の基準値を12標本以上・400ms以上で取得し、中央値とMADで外れ値を除外します。
基準更新は安定した開眼だけに限定し、閉眼/部分開眼/顔未検出/大きなスパイクでは更新しません。
顔未検出や220msを超える検出欠落後は、両目の再開眼を確認するまで受け付けません。
片目だけでの確定は誤固定を避けるため追加していません。タップは従来の共通確定処理・650ms制限を維持し、顔未検出時は無効です。

## v0.4.0-faceplay — 高速化・顔配置・特殊効果

### 計測・更新頻度

「品質・ランダム設定・その他」で品質と開発用計測表示を選べます。URLに `?debug=1` を付けても表示できます。
表示は実際に出力したフレーム数から求めたFPS、検出更新時の平均時間、フレーム当たりの変形・合成・総処理時間です。
1秒ごとに計測欄のDOMだけを更新し、計測のためにReact全体を再描画しません。
Canvas時間はCPU側の描画呼出し時間で、GPU完了時間ではありません。合成にはカメラ取り込み・ベース描画・パーツ貼り戻し・眉描画を含みます。

| 品質 | 出力長辺上限 | 局所格子 | 局所解像度 | 通常検出間隔 | 描画目標 |
| --- | --- | --- | --- | --- | --- |
| speed | 540px | 8×8 | 0.8 | 120ms | 24fps |
| balanced | 720px | 10×10 | 1 | 90ms | 30fps |
| quality | 960px | 14×14 | 1 | 65ms | 30fps |
| auto（初期値） | balanced / speed を自動選択 | 同左 | 同左 | 同左 | 同左 |

顔検出と描画を分離し、検出間のランドマークは40ms時定数の平滑化で追従します。
顔を見失ったら解除し、顔が大きく飛んだ場合は古い位置を引きずらないよう追跡を再初期化します。
速い移動を検出した後400msは、検出間隔を最大65msへ短縮して追従を優先します。
描画の時刻を繰り越して、60Hz RAFでも24fps設定が20fpsに丸められる問題を避けています。
カメラには最大30fpsを要求します。目標FPSは実機性能・撮影フレームレートによって変わり、保証値ではありません。

autoは処理負荷が高い状態が2秒続いた時にspeedへ切り替え、軽い状態が5秒続いた時にbalancedへ戻します。
内部解像度を変えてもランドマークは正規化座標のまま扱い、顔検出方式とモデルは維持しています。
保存画像も選択品質の出力解像度になります。

### 描画の無駄削減

- 全効果が標準なら領域抽出・格子生成を省略。濃さだけの変更では格子変形を行いません。
- 元画像を局所canvasへ取り込み、変形がない格子はそのまま使います。
- 局所canvasは32px単位のサイズで最大12個再利用。フェザーマスクは従来通り最大24個再利用します。
- 領域計算はランドマーク位置・フレームサイズをキーに直近の結果を再利用します。判定は0.5px単位です。
- 加工済み画像のソース再利用は引き続き禁止。下顔面、鼻、口、目、眉をすべて元カメラ画像から合成し、つながり眉を最後に描画します。

### 追加エフェクト

配置は中央集合、外側拡散、上下圧縮、上下拡張、左右接近、左右分離、上寄せ、下寄せの8種類。
個別倍率とは別の位置オフセットとして合成し、強度と横・縦の重みを持ちます。移動は各局所領域半径の28%以内へ制限します。
配置の横・縦重みは詳細表示で個別調整できます。

特殊は極太眉、つながり眉、寄り目、潰れ鼻、歪み口、下顔面拡大、上下面アンバランスの7種類。
極太眉は眉の縦倍率と濃さ、つながり眉は変形後の眉位置をつなぐ描画、寄り目は独立した位置調整です。
潰れ鼻は縦縮小・横拡大、歪み口は局所的な傾斜と中心移動を使います。
下顔面は口〜顎の楕円領域の変形で、負の値では細化します。アンバランスは上部を縮め、下部を膨らませます。
各効果は選択を変えても保持され、併用できます。個別の解除ボタンと全部リセットで解除可能です。

### プリセット・ランダム・UI

- 極太眉モンスター：極太・つながり眉、寄り目、潰れ鼻、歪み口、下顔面拡大。
- 宇宙人顔：中央集合、寄り目、やや大きい目、下顔面細化。
- 魚顔：外側拡散、おちょぼ口、下顔面拡大。
- 悪役顔：強い眉、鼻の縦倍率と軽い潰れ鼻、歪み口。

プリセットはパーツ・配置・特殊を一括設定し、その後の手動調整が可能です。
全パーツランダムのweak / normal / wildを維持し、詳細のチェックで配置・特殊も含められます。初期値は従来のパーツのみです。
特殊ランダムは疎な組み合わせとし、中央集合＋寄り目や下顔面拡大＋アンバランスの強度の重なりを抑えます。

UIはパーツ / 配置 / 特殊 / プリセットの4カテゴリ。特殊は種類選択＋単一スライダーで操作します。
3レイアウト、レイアウト保存、現在値の保持、選択パーツランダム、各リセット、写真保存を維持しています。
映像の高さはカテゴリで調整し、使わないスライダーの場所をカメラへ戻します。
