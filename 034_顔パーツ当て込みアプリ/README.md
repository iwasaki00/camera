# 顔パーツ当て込みアプリ / Portrait Face Parts Player

**Version 0.1.2 — ZOOM & MAGNIFIER**

人物画像に、自分のカメラ映像から手動で切り抜いた口元を合成するアプリです。絵画とカメラの独立した表示ズーム・パン、口元を追従する拡大鏡、枠の直接編集に対応します。外部ライブラリ・サーバーアップロード・外部通信はありません。

## 起動

このフォルダを静的Webサーバーで公開し、`index.html` を開いてください。ビルドは不要です。カメラの利用には **HTTPS または localhost** が必要です。PCで動作確認する場合は、例えばリポジトリのルートから `npx --yes http-server . -p 8080 -c-1` で配信し、`http://localhost:8080/034_顔パーツ当て込みアプリ/` を開けます（初回は配信ツールの取得が必要）。

iPhoneはHTTPSで配信したURLをSafariで開いてください。PCのLANアドレスをHTTPで開く方法ではカメラは利用できません。

### 画像選択後に表示されない場合の更新対策

UI更新直後に古いJavaScriptのキャッシュと新しいHTMLが混在すると、初期化が停止し、画像を選択できても読み込み処理が動かない場合があります。修正版ではCSS・エントリーJS・内部JSのURLに同じ更新識別子を付け、起動完了まで画像選択を無効化しました。起動失敗時も画面にメッセージを表示します。公開更新後はSafariでページを再読み込みしてください。次回の構造変更時も更新識別子を揃えて更新します。

## 使い方

1. 「画像を読み込む」で人物画像を選択します。
2. 「カメラ開始」を押し、カメラの使用を許可します。前面カメラを優先し、音声は取得しません。
3. 「枠を編集」モードで、**カメラ側のオレンジ枠**の内側をドラッグして自分の口元に合わせます。四隅をドラッグすると、絵画側の口領域と同じ縦横比で切り抜きサイズを変更できます。初期値は左右反転ONです。ピンチ開始と混同しないよう、枠の外側のタップは切り抜き位置を変更しません。
4. **絵画側の水色枠**の内側をドラッグして口の位置に合わせます。四隅で幅・高さ、上の丸で回転を調整します。形状とぼかしはプレビュー直下で切り替えられます。
5. **2本指ピンチ**で表示を拡大します。初期100%、絵画側は50〜400%、カメラ側は100〜400%です。ピンチ中心を基準に拡大・移動し、「画像を移動」モードなら1本指でも表示位置をパンできます。「鑑賞」は枠編集と1本指パンを無効にしますが、2本指操作は全モードで使えます。両プレビューの倍率スライダーと「戻す」でも操作できます。「戻す」は表示だけを100%・元の位置へ戻します。
6. **拡大鏡**は現在の口領域中心を追従します。絵画側は実際の合成結果、カメラ側は切り抜き元映像を反転設定に合わせて表示します。初期3倍、選択欄で2〜5倍に変更できます。ウィンドウのタイトル部分または映像部分をドラッグして移動し、「×」または各プレビューの「拡大鏡」で表示を切り替えます。倍率はメイン表示のズームから独立し、100%表示を基準にした倍率です。
7. 各プレビューの「枠」は個別にON/OFFできます。非表示の枠は編集対象になりません。「鑑賞」では両方の枠を一時的に非表示にします。
8. 必要なときだけ「詳細設定 / 数値で微調整」を開き、絵画側のX・Y・幅・高さ・回転・Feather、カメラ側の**切り抜き倍率**・X・Yを微調整します。直接編集の値も反映されます。切り抜き倍率は合成内容を変えますが、プレビューの**表示倍率**は合成座標を変えません。
9. 「PNG保存」で、表示ズーム・パンの影響を受けない合成PNGをダウンロードします。拡大鏡・枠・ハンドル・ガイドは入りません。iPhoneでは表示された保存用画像を長押しして「写真に保存」する方法も使えます。画像の長辺は最大2048pxです。
10. 「カメラ停止」で撮影を終了します。タブの非表示・画面離脱でもカメラを停止し、再開は手動で行います。

カメラ停止時は背景とガイドだけを表示し、停止後のPNGは背景のみになります。カメラ側拡大鏡も停止中は隠れます。画像を入れ替えると絵画側の表示だけをリセットし、口パーツ・切り抜き設定は維持します。Featherは半短径に対する内側へのぼかし率（0〜100%）です。元の口を消す処理・色合わせはないため、口元の構図と大きさを手動で合わせてください。

## 実装と確認

- `app.js`: UI・画像読み込み・描画ループ・PNG出力
- `editor.js`: CSSピクセル単位の編集枠・44px相当のハンドル判定・移動/拡縮/回転の座標変換・Pointer Eventsとpointer capture
- `viewport.js`: CSS transformによる表示だけの拡大・パン・逆座標変換・ピンチ中心の保持
- `magnifier.js`: 合成結果/元映像の中心追従・独立した倍率・フローティング表示の移動
- `camera.js`: getUserMedia・再生・停止・起動中のキャンセル
- `renderer.js`: パーツ描画・切り抜き・楕円/四角マスク・境界ぼかし（SafariのCanvas filterに依存しません）
- `npm test`: 切り抜き座標・マスク・カメラのライフサイクル、回転状態の拡縮、ハンドル判定、50/100/200/400%の逆座標変換、ピンチ中心など19件のテスト
- `npm run test:browser`: Chromeの疑似カメラで既存操作に加え、両プレビューの100/200/400%編集、拡大後の回転枠の拡縮、3モードすべてのピンチ、片指を離した後の安定性、枠非表示時の操作抑止、拡大鏡の移動/表示/倍率/追従/ミラー、ズーム前後のPNG画素一致、カメラ停止/再開を確認します。Windowsの標準Chromeパスを使用し、別環境では `CHROME_PATH` に実行ファイルを指定してください。`BROWSER_WIDTH` / `BROWSER_HEIGHT` / `BROWSER_DPR` で画面条件を変更できます（初期値390 / 844 / 1）。
- 環境変数 `SIMULATE_STALE_CACHE=1` で、未更新のJS URLに旧UI向けの初期化処理を返す条件と起動遅延を再現できます。この条件でも起動・画像読込・保存が成功し、準備中は画像を選択できないことを確認します。

iPhone Safari実機は未確認です。実機では、2本指ピンチと片指へ戻した時の挙動、スクロール/ダブルタップとの競合、フローティング拡大鏡の指操作、前面カメラの反転・停止/再開、横向きへの回転、PNGの長押し保存を確認してください。Chromeの疑似カメラ・画面エミュレーションの結果で実機確認を代替していません。

## 対象外 / 次の候補

枠編集は1本指、表示ズームは2本指です。2本目の指を置く直前に枠がわずかに動いても、その編集を開始時へ戻してからピンチへ移ります。2本指回転・慣性パンはありません。2本指操作の後はすべての指を離してから次の編集を始めてください。プレビュー内では全モードでページスクロールを抑止するため、画面の外側や操作パネルをスワイプしてください。表示を見失った場合は「戻す」で復帰できます。画面回転・レイアウト変更時は進行中のジェスチャーを解除します。プロジェクト内のテキストは `.gitattributes` でLFに統一しています。

拡大鏡ウィンドウ上のドラッグはウィンドウ移動として扱います。重なって操作しづらい時は移動するか非表示にしてください。画像の端では拡大鏡の一部が暗い余白になります。絵画の端で枠の一部が画像外に出た場合は、表示パンまたは詳細設定で調整してください。カメラ側の枠拡縮は縦横比固定・切り抜き倍率1〜6倍の範囲です。表示倍率・位置・拡大鏡の配置は保存しません。

左目・右目・鼻、ランドマーク検出、自動追従、テンプレートJSON、複数テンプレート、動画保存は未実装です。設定は再読込でリセットされます。

次の候補は **Version 0.2.0 — MOUTH ALIGNMENT & TEMPLATE**：iPhone実機での調整体験を改善し、口領域と切り抜き設定のJSON保存/読込を追加する案です。
