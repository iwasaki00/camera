# 顔パーツ当て込みアプリ / Portrait Face Parts Player

**Version 0.9.0 — FREE PARTS FOUNDATION**

カメラの好きな範囲を、画像上の好きな場所へ合成する端末内Webアプリです。口・目などの固定分類を廃止し、手・物体・複数部位などを1〜8個の汎用パーツとして扱います。自動顔追従はありません。

## 基本操作

1. HTTPSまたはlocalhostで開き、「画像読込」から背景を選び、「カメラ開始」を押します。カメラは映像のみ取得し、録画でマイクONを選んだ時だけ音声許可を要求します。
2. **絵画／カメラ／完成**の3タブを切替。絵画で配置、カメラで切り抜き、完成でガイドのない合成結果を確認します。タブ切替でカメラや録画を再起動しません。
3. 初期状態は中央の楕円「パーツ1」1個。**＋ パーツ追加**で最大8個まで追加できます。選択一覧だけを横スクロールでき、選択項目は自動で一覧内へ収まります。
4. **調整 → A. パーツ・ぼかし**で名前変更・複製・合成ON/OFF・確認付き削除、4種類の重なり順操作、形状・Feather、配置数値を調整。最後の1個は削除できません。名前は1〜40文字のテキストです。
5. **B. カメラ・切り抜き**で左右反転、X/Y、倍率0.6〜6、切り抜き縦横比0.1〜10を調整。枠のドラッグ・サイズ変更も利用できます。新規パーツのカメラ枠は1:1で、縦横比設定から任意の矩形へ変えられます。
6. 「枠を編集／画像を移動／鑑賞」、2本指ピンチ、ズーム・パン・全体表示、選択パーツへ「寄る」、画像・カメラで独立した2〜5倍の拡大鏡を利用できます。拡大鏡は初期収納、ドラッグ移動可能です。
7. **C. 色調・質感**でORIGINAL／NATURAL／COMICとパーツ個別の補正を選びます。ORIGINALは従来の補正なし。NATURALの自動色合わせは手動でON/OFFできます。補正前の比較表示はPNGや動画の正式な補正設定を変えません。

## 保存・テンプレート

- **PNG保存**は有効な全パーツを重なり順に合成。編集枠・拡大鏡・表示ズーム・操作UIは保存しません。
- **保存・読込**からIndexedDB内へ新規保存・上書き・別名保存・名前変更・複製・削除、ZIP入出力を利用できます。背景とパーツ設定を保存し、カメラ映像や顔画像は保存しません。
- 文書スキーマは**4**（汎用パーツ最大8個）。IndexedDBの物理DBバージョンは**1のまま**です。
- 旧スキーマ1・2・3は読み込み可能。旧IDと手動配置・切り抜き等を維持し、mouth→口、leftEye→左目、rightEye→右目、nose→鼻の名前へ変換。旧自動追従は使用せず、**最後に保存された手動切り抜き位置**を復元します。
- 旧版の独立縦横比がないパーツは、従来どおり配置先の比率で切り抜きます。新しい縦横比を設定するまで従来の見た目を保ちます。旧0パーツは「パーツ1」を補完します。
- 読み込むだけでは旧テンプレートを上書きしません。ZIPは`template.json`と背景画像を含む単一ファイルです。新規保存・書出はスキーマ4になります。

## ショート動画

**D. 録画設定**に時間15／30／60秒、マイク（初期OFF）、画質、比率・画角、カウントダウン、タイトル、フェード、出力プレビューを収納しています。

- 元画像比率：標準は長辺720px／24fps、低負荷480px／15fps。9:16：標準360×640／24fps、低負荷270×480／15fps。
- FITは全体＋単色余白。FILLは画面を満たし、切り取り中心X/Yで調整。出力だけに作用し、パーツ座標やPNGを変更しません。
- カウントダウンは初期ON。マイクと録画資源を準備してから3・2・1を表示し、終了後に実際の録画を開始。キャンセル可能で、数字は動画に入りません。タブ切替は継続、カメラ停止・画面非表示・離脱時は安全に終了します。
- タイトルは空欄／表示なしが初期値。冒頭2秒／全編／指定時間の最後2秒を選択。日本語・長文を改行・縮小して表示します。フェードは初期OFFで、ONなら指定時間内の映像のみ約0.4秒。途中停止に終了演出を後付けしません。
- 出力プレビューは同じ合成結果を最大5Hzで表示し、閉じた時は更新を止めます。確認時点を動かして文字・フェードの表示を確認できます。
- MP4優先・WebMフォールバックで実形式と拡張子を一致させます。終了後は再生・保存・共有を利用し、保存先で確認してください。未保存動画の置換確認とデータ保持を維持しています。

**E. 詳細・診断・ヘルプ**に描画fps・合成時間・録画診断とテキストコピーを用意。顔検出専用の表示は削除しました。画像・映像・音声は外部サーバーへ送信しません。

## 開発・検証

フロントエンドのみ。既存のNode環境で`npm test`、`npm run test:free`、`npm run test:composite`、`npm run test:recording`、`npm run test:short`、`npm run test:picker`を利用できます。`npm run test:performance`は1／4／8パーツの録画OFF/ONを比較します。ブラウザテストにはローカルChrome、動画解析にはffprobe／ffmpegを使用します。WebKitは既存のローカルPlaywright設定を使用します。実行結果は`reports/v0.9.0-*`に記録。

新しいライブラリ・有料APIは追加していません。ZIP用の**fflate 0.8.2 / MIT**を引き続きローカル配布（[利用条件](vendor/README.md)）。MediaPipe、顔モデル、顔追従Worker・専用コードは削除しました。

[実装・移行・性能・テスト・iPhone確認事項](docs/FREE_PARTS_v0.9.0.md)を参照してください。Windowsのブラウザテスト成功はiPhone Safari実機の成功を意味しません。iPhoneでの実カメラ・音声同期・保存／共有・8パーツ時の性能は未確認です。写真アプリへの直接保存やOS強制終了後の動画復元は保証しません。
