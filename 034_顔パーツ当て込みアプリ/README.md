# 顔パーツ当て込みアプリ / Portrait Face Parts Player

**Version 0.1.1 — DIRECT TOUCH EDITOR**

人物画像に、自分のカメラ映像から手動で切り抜いた口元を合成するアプリです。写真とカメラの枠を直接ドラッグして調整できます。外部ライブラリ・サーバーアップロード・外部通信はありません。

## 起動

このフォルダを静的Webサーバーで公開し、`index.html` を開いてください。ビルドは不要です。カメラの利用には **HTTPS または localhost** が必要です。PCで動作確認する場合は、例えばリポジトリのルートから `npx --yes http-server . -p 8080 -c-1` で配信し、`http://localhost:8080/034_顔パーツ当て込みアプリ/` を開けます（初回は配信ツールの取得が必要）。

iPhoneはHTTPSで配信したURLをSafariで開いてください。PCのLANアドレスをHTTPで開く方法ではカメラは利用できません。

## 使い方

1. 「画像を読み込む」で人物画像を選択します。
2. 「カメラ開始」を押し、カメラの使用を許可します。前面カメラを優先し、音声は取得しません。
3. **カメラ側のオレンジ枠**の内側をドラッグして自分の口元に合わせます。四隅をドラッグすると、写真側の口領域と同じ縦横比で切り抜きサイズを変更できます。枠の外側のタップでも位置を指定できます。初期値は左右反転ONです。
4. **写真側の水色枠**の内側をドラッグして口の位置に合わせます。四隅で幅・高さ、上の丸で回転を調整します。形状とぼかしはプレビュー直下で切り替えられます。
5. 必要なときだけ「詳細設定 / 数値で微調整」を開き、写真側のX・Y・幅・高さ・回転・Feather、カメラ側の倍率・X・Yをスライダーで微調整します。直接操作の値も反映されます。「編集モード」をOFFにすると枠とハンドルが消え、プレビュー上でもページをスクロールできます。
6. 「PNG保存」で、編集枠・ハンドルを除いた合成PNGをダウンロードします。iPhoneでは表示された保存用画像を長押しして「写真に保存」する方法も使えます。画像の長辺は最大2048pxです。
7. 「カメラ停止」で撮影を終了します。タブの非表示・画面離脱でもカメラを停止し、再開は手動で行います。

カメラ停止時は背景とガイドだけを表示し、停止後のPNGは背景のみになります。画像を入れ替えると調整値は維持されます。Featherは半短径に対する内側へのぼかし率（0〜100%）です。元の口を消す処理・色合わせはないため、口元の構図と大きさを手動で合わせてください。

## 実装と確認

- `app.js`: UI・画像読み込み・描画ループ・PNG出力
- `editor.js`: CSSピクセル単位の編集枠・44px相当のハンドル判定・移動/拡縮/回転の座標変換・Pointer Eventsとpointer capture
- `camera.js`: getUserMedia・再生・停止・起動中のキャンセル
- `renderer.js`: パーツ描画・切り抜き・楕円/四角マスク・境界ぼかし（SafariのCanvas filterに依存しません）
- `npm test`: 切り抜き座標・マスク・カメラのライフサイクル、回転状態の拡縮、移動/回転/ハンドル判定など15件のテスト
- `npm run test:browser`: Chromeの疑似カメラを使い、タッチイベントで写真の移動/拡縮/回転、キャンセル後の再操作、カメラ側の移動/拡縮、反転時の座標、編集モード、折りたたみ、スクロール位置の維持、画像読込/失敗、カメラ開始/停止/拒否、PNG画素一致とガイド除外を確認します。Windowsの標準Chromeパスを使用し、別環境では `CHROME_PATH` に実行ファイルを指定してください。`BROWSER_WIDTH` / `BROWSER_HEIGHT` / `BROWSER_DPR` で画面条件を変更できます（初期値390 / 844 / 1）。

実機確認時はiPhone Safariで、縦横の画像読み込み、カメラ許可/拒否、開始/停止、背景移動後の停止、口元の切り抜き、各調整、反転、PNGの長押し保存を確認してください。自動テストは実機の権限・カメラ・写真アプリへの保存を保証しません。

## 対象外 / 次の候補

直接編集は1本指のドラッグ操作です。ピンチや2本指回転は未対応です。編集中のプレビュー内ではページスクロールを抑止するため、画面外側をスワイプするか編集モードをOFFにしてください。写真の端で枠の一部が画像外に出た場合は、枠を中央へ戻すか詳細設定で調整してください。カメラ側の拡縮は縦横比固定・切り抜き倍率1〜6倍の範囲です。自動追従はありません。

左目・右目・鼻、ランドマーク検出、自動追従、テンプレートJSON、複数テンプレート、動画保存は未実装です。設定は再読込でリセットされます。

次の候補は **Version 0.2.0 — MOUTH ALIGNMENT & TEMPLATE**：iPhone実機での調整体験を改善し、口領域と切り抜き設定のJSON保存/読込を追加する案です。
