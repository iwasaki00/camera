# iPhone Safari録画確認 — v0.6.2

対象：顔パーツ当て込みアプリ / Portrait Face Parts Player

**この資料作成時点でiPhone実機は未検証です。PCのPASSはiPhoneの合格を意味しません。** 以下はiPhoneとSafari・メモ・ファイルだけで実施できます。検証には保存してよい画像を使ってください。顔や音声を含む動画は、許可した保存先・共有先以外へ送らないでください。

## 1. 公開版Versionの確認

1. 普段の公開URLをSafariで直接開きます。自作エミュレータや他アプリ内のブラウザは今回の対象外です。
2. ページ上部の **v0.6.2** と最下部の **Version 0.6.2 — RECORDING RELIABILITY & UX** を確認します。
3. 旧版の場合はSafariで再読み込みし、必要なら同じURLを新しいタブで開きます。旧版のままなら公開担当へ確認します。保存済みテンプレートを消す操作は不要です。
4. 「追従・録画の診断（初期OFF）」を開き、コピーしたテキストの先頭もv0.6.2であることを確認します。HTTPSで開いてください。

準備：画像を読み込み、カメラを開始。まず口だけ・手動・ORIGINALで合わせます。録画設定は標準720px / 24fps、端末負荷が高ければ低負荷480px / 15fpsも別条件として試します。録画中にアプリを切り替えないでください。

## 2. 15秒無音録画

1. 「録画設定」で時間15秒・マイクOFF。録画前の診断では対応APIを確認します。
2. 「録画開始」を1回押します。録画中の赤い停止ボタン・状態・経過時間を確認します。口を動かし続けます。
3. 約15秒で「終了処理中」→「録画完了」となり、録画済み動画の画面が開くことを確認します。
4. 「再生」で口が動くこと、約15秒であること、編集枠・ハンドル・拡大鏡・UIが映っていないことを確認します。
5. 続けて途中停止も試します。「録画停止」は連打しても多重終了にならないことを確認します。

## 3. 音声付き録画

1. 時間15秒・マイクON。**録画開始を押した後だけ**マイク許可が出ることを確認し、許可します。既に許可済みなら再表示されない場合があります。
2. 録画中に短い言葉を話します。診断のマイクON／取得状態acquired、音声トラックliveを確認します。
3. 終了後に再生して、話した内容が聞こえることを確認します。再生音量・消音設定も確認してください。
4. 終了後の診断がREADY、マイクreleased、音声トラックendedになることを確認します。カメラの使用は別に継続します。
5. マイクを拒否するテストも可能な範囲で実施します。拒否の説明が出て、「音声なしで録画」で再試行できることを確認します。無音のときにマイク許可を要求しないことも確認します。

## 4. 音声同期

- 1秒間隔で「パッ」を3回言い、口の開く瞬間と音を再生で比較します。録画の序盤・中盤・終盤で繰り返します。
- 手拍子を使う場合は、**手を叩く動きが切り抜き範囲に映るように**テスト用の範囲を広げます。口だけの小さな枠では手の動きが保存されません。
- 「音が先／口が先／目立たない」「時間とともにずれが増えるか」を記録します。iPhoneのスピーカーで一度確認し、Bluetoothイヤホン等の遅延は別条件として扱ってください。
- PCテストの音声トラック存在・開始時刻一致だけでは、この発話同期は合格にしません。

## 5. MP4 / WebMの保存

1. 結果画面の形式・サイズを確認し、「動画を保存」を押します。保存操作の案内はSafariの表示に従います。
2. 保存先の「ファイル」等で対象動画を見つけ、サイズが0でないこと・再生できること・長さと音声を確認します。
3. Safariに戻って結果をもう一度再生します。保存操作だけで結果が失われないことを確認します。
4. 保存先で確認できたら **「保存先で確認済み」** を押します。保存リンクのクリックや共有完了だけでは、アプリは保存成功を断定しません。
5. 保存できなければ「保存リンクを作り直す」で再試行します。結果画面を閉じても「録画結果」から戻れます。再読み込みはしないでください。

実際に選ばれたMIMEと拡張子を記録します。MP4が選ばれた場合、WebMは「未確認」で構いません。WebMが保存できてもiPhoneの再生環境が対応しない可能性があります。その場合は「保存OK／再生NG」と分けて記録します。拡張子を手作業で変更しないでください。「写真」への直接保存は保証対象ではありません。

## 6. 共有・未保存保護

1. 「共有」が使えれば共有画面を開き、一度キャンセルします。結果を再生できることを確認します。
2. 自分が許可した共有先へ渡し、その共有先で再生を確認します。「写真」等が選べるかは環境次第です。
3. 共有非対応なら案内と「動画を保存」が利用できることを確認します。
4. 未保存のまま「録り直す」、または結果画面を閉じて「録画開始」を押します。置き換え確認をキャンセルし、動画が保持されることを確認します。
5. カメラ停止中に「録り直す」を押した場合、動画を消さず再開方法を案内することを確認します。
6. 保存してよいテスト動画でのみ、未保存のまま再読み込みや移動を試します。対応環境では離脱確認が出ますが、**iPhoneで警告が出るとは限りません。** 大切な録画で離脱を試さないでください。

## 7. 30秒・60秒録画と負荷

30秒、次に60秒を選び、自動停止・動画の長さ・映像の変化・音声・ファイルサイズを確認します。途中で縦横回転し、停止ボタンを操作できること、動画の縦横比や解像度が勝手に変わらないことも確認します。

## 8. 診断ログのコピー

1. 編集画面の「追従・録画の診断（初期OFF）」を開きます。録画中もコピーできます。結果画面が重なっていれば一度「閉じる」を押します（動画は保持されます）。
2. 5秒程度待って「診断テキストをコピー」を押します。失敗時は下のテキスト欄を選択してコピーします。
3. **録画中はメモへ切り替えず、停止してから**貼り付けます。アプリを切り替えると録画・カメラを停止する仕様です。
4. 終了後のログもコピーします。MIME、音声状態、チャンク数、最終サイズ、終了理由、最終エラーを残してください。

描画・検出・合成は直近5秒の窓。録画のチャンク数・サイズは今回の累計です。生成途中のサイズはブラウザによって0のままになる場合があります。最終dataavailable後の値で判断してください。診断に動画・音声・顔画像・トラックIDは含めません。診断を閉じると表示更新を止めます。

## 10. 既知の制限

- iPhone実機の録画・同期・保存・共有・性能は、この資料では全項目未確認です。
- 対応形式・ファイル共有・保存先・動画再生可否はSafariとOSに依存します。写真アプリへの直接保存は保証しません。
- 録画はメモリ内の1件のみ。ページ破棄・OSによる終了・再読み込みで失われます。離脱警告や最後のチャンク確定が間に合うとは限りません。
- 画面非表示・カメラ停止で録画を終了します。バックグラウンド録画には対応しません。
- 設定fpsは目標で、実際の録画fpsやビットレートとは異なります。診断の描画fpsも、動画のエンコードfpsとは別です。
- Web Share APIの完了やダウンロードリンクのクリックは、保存先での保存成功を保証しません。端末側で確認してください。
