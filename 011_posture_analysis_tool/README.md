# Posture Lens（姿勢解析ツール）

iPhone Safariのカメラ映像からMediaPipe Pose Landmarkerで人体ランドマークを検出し、姿勢の傾きや左右差を簡易表示する、サーバー不要のWebアプリです。

## 使用技術

- HTML / CSS / JavaScript（ES Modules）
- Canvas API
- MediaDevices `getUserMedia()`
- MediaPipe Pose Landmarker for Web
- localStorage

## 起動方法

ES ModulesとカメラAPIを使用するため、ファイルを直接開かずWebサーバーから配信してください。PCでは `localhost`、iPhoneではHTTPSで公開されたURLを開きます。HTTPSが必要なのは、ブラウザがカメラAPIを安全なコンテキストに限定しているためです。

## iPhoneでの使い方

1. SafariでHTTPSのURLを開き「カメラを開始」をタップします。
2. カメラの使用を許可し、全身が枠内に入る位置へ移動します。
3. 正面・左側面・右側面を選び、姿勢を静止して「解析」をタップします。
4. 必要に応じて結果を保存し、履歴で2件を選んで比較します。

撮影済み写真を使う場合は「画像」または「撮影済み画像を選ぶ」をタップし、写真ライブラリから全身写真を選択します。選択中の解析方向で自動解析されます。

## 主な機能

- 背面／前面カメラ切替
- 撮影済み画像の読み込みと静止画姿勢解析
- リアルタイム骨格、グリッド、中心線、数値オーバーレイ
- 正面／左右側面解析
- 直近8フレームの平均化
- 端末内への解析履歴保存・削除
- 2件のBefore / After比較
- 簡易デバッグ表示

## 制約事項

- 絶対寸法のキャリブレーションを行わないため、cmではなく角度と画面内比率で表示します。
- 衣服、照明、遮蔽、撮影距離により精度が変化します。
- 結果は医療診断ではありません。
- MediaPipeのモデルと実行ファイルは初回起動時にCDNから読み込みます。

## 今後の拡張

身長などを用いた寸法キャリブレーション、画像付き履歴、CSV出力、PWA対応、トレーニング前後の管理を追加できるよう機能をモジュール分割しています。

## 安定性と操作

- カメラ起動中の重複要求と、入力切替後に完了した古い要求を無効化します。
- カメラ解析は、有効な全身ランドマークが直近8フレーム揃ってから実行できます。計算式・検出閾値・正面／左右側面の指標は従来どおりです。
- 画像を選ぶとカメラを停止します。画像モードの「カメラ」ボタンで明示的に再起動します。
- ページが非表示になるとカメラとライブ描画を停止します。復帰後は「カメラを開始」で再開してください。解析済み結果・履歴と、読込済み画像は保持します。読込途中の画像は再選択してください。
- 保存成功後は同じ解析結果を重複保存しません。保存・削除失敗時は再試行できます。履歴は従来と同じ形式でlocalStorageに最大40件保存し、外部サーバーへ送信しません。
- スコアは100点満点の参考値です。カメラの角度・距離・衣服・照明によって変動し、医療診断や健康状態の確定評価には使えません。

## 関連テスト

静的Webアプリのまま、ビルド工程はありません。Node.jsで状態管理の限定テストを実行できます。

```sh
node --experimental-vm-modules tests/stability.mjs
```

カメラ起動・中断・切替・再試行、play失敗、描画ループの重複、画像の競合、モデルの共有初期化とモード切替、古い結果の無効化、8フレーム保持、履歴の保存・削除・比較を模擬環境で検証します。CDNの実モデルや実カメラは使用しません。

PlaywrightとChromiumが導入済みの環境では、次の任意のレイアウトテストも実行できます。アプリ自体への追加依存はありません。

```sh
node tests/layout.cjs
```

Playwrightが通常のモジュール検索パスにない場合は `POSTURE_PLAYWRIGHT` にモジュールのパス、ブラウザを明示する場合は `POSTURE_CHROMIUM` に実行ファイルのパスを指定します。320×568、375×667、390×844、430×932、844×390、PC（1280×900）で、主要操作の位置・横幅・ダイアログ内部スクロールを確認します。

iPhone実機でのSafariのカメラ権限・前後切替・バックグラウンドからの復帰、MediaPipeの実姿勢推定、画像形式ごとの読込、localStorage保存は未確認です。Safe Area、ピンチズーム、ダブルタップ・長押しの体感も実機での確認が必要です。
