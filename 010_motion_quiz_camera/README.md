# Motion Quiz Camera

iPhone Safariのカメラ映像から姿勢を推定し、人の動きを骨格アニメーションに変えてクイズとして保存する静的Webアプリです。映像、骨格動画、姿勢座標は端末内で処理し、作品はIndexedDBに保存します。

## 起動方法

ビルドは不要です。リポジトリ直下でローカルサーバーを起動してください。

```sh
python -m http.server 8000
```

PCでは `http://localhost:8000/010_motion_quiz_camera/` を開きます。iPhoneから利用するときは、GitHub PagesなどのHTTPS環境へ配置してください。

## 使い方

1. 「カメラを開始」を押し、カメラの利用を許可します。
2. 全身が映る位置に立ち、録画時間と骨格の見え方を選びます。
3. 録画ボタンを押すと3秒後に撮影が始まります。
4. 撮影後にタイトル、答え、必要ならヒントを入力して保存します。
5. 「作品」から骨格だけのクイズ動画を再生し、「答えを見る」で正解を表示します。

## 実装内容

- 前面・背面カメラの切り替え
- MediaPipe Pose Landmarkerによる最大33点の姿勢推定
- 元動画、骨格重ね表示、骨格のみ表示のライブプレビュー
- 3 / 5 / 10 / 15秒録画と3秒カウントダウン
- 元動画とCanvas骨格動画の同時録画
- 全フレームの姿勢座標、信頼度、時刻をJSON互換データとして保持
- かんたん / ふつう / むずかしい / 激ムズの骨格表示
- IndexedDBへの動画Blob、JSON、サムネイル、クイズ情報の保存
- 作品一覧、詳細、答えの表示・非表示、0.5x〜2x再生、ループ、削除

## iPhone Safariでの注意

- カメラはHTTPSまたはlocalhostの安全な接続でのみ利用できます。
- カメラと動画再生はユーザー操作から開始します。動画要素には `playsinline` を指定しています。
- 録画形式は `MediaRecorder.isTypeSupported()` でMP4を優先し、利用できない場合はWebMを選びます。
- `canvas.captureStream()` に対応しない端末では骨格動画Blobを作れない場合があります。その場合も姿勢JSONからアプリ内の骨格再生はできます。
- MediaPipeのライブラリ、WASM、学習済みモデルは初回にCDNから読み込むため、通信が必要です。
- 長い録画や作品の大量保存は端末のメモリとストレージを消費します。初期設定は5秒、最大15秒です。
- Safariのプライベートブラウズや空き容量不足ではIndexedDB保存に失敗することがあります。

## 既知の制約

- 骨格は2Dの推定結果であり、身体が隠れる動き、暗所、画面外に出る動きでは精度が下がります。
- 元動画に音声は保存しません。
- 保存作品はブラウザ内にだけ残ります。サイトデータを削除すると作品も消えます。
- iOS / Safariの世代によってCanvas録画の形式と共有可能なファイル形式が異なります。

## v2026.10.17.1 の状態管理と確認

- 撮影状態は idle / countdown / recording / finalizing / review / error で管理します。カウントダウンは3秒で、画面内の「キャンセル」から中断できます。作品画面への移動やカメラ切替でも中断します。
- カメラ要求は世代で管理し、古い取得結果を停止します。映像の再生失敗・読み込みエラー・15秒の待機タイムアウト後も再試行できます。
- 録画エラー時は2本の停止処理を共有し、最大4秒の終了待機後に取得済みデータを返します。骨格Canvasのトラックは解放し、カメラトラックはカメラ側で管理します。不完全な動画は再生できない場合があり、確認画面に失敗内容と保存可能なデータを表示します。
- 画面非表示・pagehideではカメラと描画を停止し、録画中なら停止処理を始めます。復帰時にカメラや録画を自動再開しません。撮影結果を確認後、「端末に保存」を押してください。SafariやOSの強制終了時にデータを必ず保存できるものではありません。
- 保存中は再保存と画面移動を制限し、IndexedDBのトランザクション完了を確認します。失敗時は入力と撮影結果を保持して再試行できます。DB名・バージョン・既存作品のフィールド形式は変更していません。
- 元動画・骨格動画・姿勢JSONはサーバーにアップロードしません。保存先は端末内のブラウザ保存領域です。姿勢AIを読み込めない場合や有効な姿勢データがない場合は骨格クイズを作成できない旨を案内します。

### 関連テスト

ビルドや追加パッケージのインストールは不要です。Node.js 22以降で対象アプリのディレクトリから実行します（実行確認: Node.js 25.9.0）。

~~~sh
node --test tests/lifecycle.test.mjs
node tests/browser-check.mjs
~~~

状態・競合テスト18件で、カウントダウンのキャンセル、古いカメラ要求、play失敗、loadeddataの中断・エラー・タイムアウト、録画エラーと終了待機、トラック解放、保存失敗時の保持・重複防止を確認します。

ブラウザテストはWindowsの標準インストール先のChromeをヘッドレスで起動します。別の場所やChromium系ブラウザを使う場合は環境変数 BROWSER_PATH に実行ファイルを指定してください。一時プロファイルとlocalhostの静的サーバーを使用し、実際のカメラ・マイクは使いません。

320×568、375×667、390×844、430×932、844×390および1280×800で横はみ出しと操作位置を確認しました。320px幅と横画面は画像でも確認しています。Canvasのテスト映像から元動画・骨格動画を同時生成し、トラック解放、既存形式の作品保存・一覧・詳細・答え表示・元動画再生・0.5x・ループ設定・閉じる処理・保存失敗後の保持を確認しました。
