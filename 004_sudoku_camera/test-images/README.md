# OCR test images

## sudoku-sample-01

- `sudoku-sample-01.png`: 900×900pxのOCR検証用ナンプレ盤面。白背景、黒い罫線と数字、30個の印刷数字を含みます。
- `sudoku-sample-01.json`: 画像に印刷されている数字だけを行優先で並べた81要素の正解データです。空欄は`0`です。完成解答ではありません。
- `generate-sudoku-sample-01.ps1`: PNGを同じ内容で再生成するPowerShellスクリプトです。
- `sudoku-sample-02.png` / `.json`: 数字配置とフォントサイズを変えた第2の独自生成テスト盤面です。30個の印刷数字を含みます。
- `generate-sudoku-sample-02.ps1`: 第2サンプルを再生成するスクリプトです。

アプリの「DEBUG / テスト画像入力」を開き、「サンプル01を読み込む」を押すと、画像と正解データが同時に読み込まれます。

独自生成の固定テストデータで、外部画像や第三者素材は使用していません。
