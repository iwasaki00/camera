# ナンプレ カメラ読み取り

**v1.0.0 — Initial Stable Release**

iPhoneカメラでナンプレ問題を撮影し、数字の読み取り、手修正、矛盾チェック、解答、解き方のStep解説まで行えるWebアプリです。

## 主な機能

- iPhone Safariの背面カメラと固定9×9ガイド
- 撮影画像の上下左右・ズーム・0.1度単位の回転調整
- 81セルへの分割とTesseract.jsによる数字読み取り
- セルタップ式ミニテンキーによる読み取り結果の修正
- 行・列・3×3の重複と読み取り不確かなセルの確認
- 問題数字を保持したナンプレ解答表示
- 盤面、候補、除外理由を使ったStep形式の解き方表示
- PC画像ファイルと同梱サンプルを使ったブラウザ検証

## 基本的な使い方

1. ナンプレを9×9ガイドへできるだけ正面から合わせ、映像をタップして撮影します。
2. 必要な場合は「位置を調整」を開き、盤面の位置、拡大率、傾きを微調整します。
3. 「数字を読み取る」を押します。
4. 読み取り結果を確認し、違うセルがあればタップして1～9または消去を選びます。
5. 完成した答えは「答えを見る」、1手ずつ確認する場合は「解き方を見る」を選びます。

## 対応環境

主対象はiPhone Safariです。PCブラウザでも「詳細設定・診断（PC画像入力）」からPNG、JPEG、WebPファイルまたは同梱サンプルを読み込んで検証できます。

## 数字読み取り

数字読み取りにはTesseract.jsを使用しています。盤面を81セルへ分割し、各セル用に整えた画像から1～9を読み取ります。読み取り後は必ず盤面を確認し、必要に応じてセルを手修正してください。

## 解き方のStep表示

現在は次の基本的な解き方に対応しています。

- 候補が1つ
- 行で1か所
- 列で1か所
- 3×3で1か所

「なぜ？」を開くと、候補の×／○、除外理由、原因となる盤面上の数字を確認できます。対応している解き方だけで先へ進めない場合は、無理な説明を作らず停止します。高度な解法は将来拡張です。

## 詳細設定・診断

通常操作では折りたたまれています。PC画像入力、サンプル入力、81セル確認、1セル数字読み取り、入力画像、confidence、Benchmark、OCR TUNING、Crop、Threshold、PSM、Padding、Solve Timeなどの検証情報を維持しています。

## 現在の制限

- 透視変換や四隅補正は行いません。撮影時は盤面をガイドへできるだけ正面から合わせてください。
- 解き方表示は上記4種類の基本解法のみ対応しています。
- Solverは解を1つ求めますが、問題に複数解が存在するかどうかの一意解判定は行いません。
- 写真の傾き、影、反射、数字の書体によっては読み取り結果の手修正が必要です。
- カメラの実際の動作と操作感はiPhone実機での確認が必要です。
