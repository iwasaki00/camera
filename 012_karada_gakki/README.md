# カラダ楽器

iPhone Safari のカメラで顔・体の動きを検出し、Web Audio API で音を鳴らすMVPです。映像は端末上だけで処理され、アップロードされません。

## 起動

カメラAPIの制約により、HTTPS または `localhost` で配信してください。静的ファイルだけで動作します。

```text
012_karada_gakki/
├── index.html
├── style.css
├── app.js
├── js/
│   ├── camera.js          カメラ制御
│   ├── audio.js           音声素材・合成音の再生
│   ├── faceMode.js        顔ランドマークと表情判定値
│   ├── bodyMode.js        姿勢ランドマークと動作判定値
│   ├── motionTracker.js    体パーツ速度の平滑化・音量変換
│   ├── actionDetector.js  inactive/active/cooldown 状態管理
│   ├── settings.js        初期割り当て・設定保存
│   └── vision.js          MediaPipe設定
└── assets/audio/          任意のWAV素材配置先
```

音声素材が無い状態では軽量な合成音が鳴ります。実素材を使う場合は `audio.js` の `SOUND_FILES` に対応するパスへ `kick.wav` などを配置してください。

## iPhone Safari の注意点

- カメラは HTTPS または localhost 以外では起動できません。
- カメラ許可と音声有効化は「はじめる」ボタンのタップを起点にしています。
- 必ず Safari のカメラ権限を許可してください。埋め込みブラウザでは動かない場合があります。
- 端末の発熱を抑えるため推論を最大24fpsに制限し、選択中の顔・体モデルだけを生成します。
- 顔モードは顔が十分大きく映る距離、体モードは頭から足首まで入る距離で使ってください。
- マナーモードや本体音量の設定により聞こえ方が変わります。
- 初回はMediaPipe本体とモデルをCDNから取得するため、ネット接続が必要です。

## 誤発音防止

各動作は `inactive → active → cooldown` の状態を持ちます。閾値を初めて越えたフレームだけ発音し、いったん元の姿勢へ戻り、設定したクールダウンを経過するまで再発音しません。戻り判定にはヒステリシスを設けています。

## 感度と演奏強度

顔・体の全アクションは、それぞれ独立した感度を設定でき、値は端末内に保存されます。感度を上げるほど判定閾値が下がり、小さな動きでも反応します。

体モードは手首・足首のフレーム間移動を `MotionTracker` で平滑化し、発音時の音量を 0.25〜1.0 に変換します。低信頼ランドマーク、極端に短いフレーム間隔、長い認識断、異常な座標ジャンプは速度計算から除外します。両手アクションには左右の手のうち速い方を採用します。

## iPhone実機確認項目

1. 各動作の感度変更が判定へ反映される
2. 感度・クールダウン・音量が再読み込み後も残る
3. ゆっくり手を上げると小さく鳴る
4. 強く手を上げると大きく鳴る
5. 上げっぱなしで連打されない
6. 左右の手で速度がそれぞれ計算される
7. DEBUGの `SPD` / `VOL` が動きに応じて変わる
8. FPSが改修前から極端に低下しない
9. 顔モードが従来どおり動作する
10. 体モードの既存アクションが従来どおり認識される
