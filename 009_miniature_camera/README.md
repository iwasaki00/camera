# Miniature Camera

iPhone Safari向けのティルトシフト風カメラです。中央のピント帯を残して上下を段階的にぼかし、彩度・コントラストを補正したプレビューをリアルタイム表示します。画面に表示している加工済みCanvasそのものを写真または動画として保存します。

## 起動方法

静的ファイルのためビルドは不要です。HTTPSで配信するか、開発時はリポジトリ直下でローカルサーバーを起動します。

```sh
python -m http.server 8000
```

`http://localhost:8000/009_miniature_camera/` を開いてください。カメラは安全なコンテキスト（HTTPSまたはlocalhost）でのみ利用できます。

## GitHub Pages

リポジトリの Settings → Pages で公開ブランチとルートを選択します。公開後は `https://<user>.github.io/<repository>/009_miniature_camera/` から利用できます。

## iPhoneでの使い方

1. Safariでページを開き「カメラを開始」をタップし、カメラを許可します。
2. プレビューを上下ドラッグしてピント位置、2本指ピンチでピント幅を調整します。
3. プリセットまたは調整パネルで、ぼかし・位置・幅・角度・色を変更します。
4. 写真／動画を選び、中央のボタンで撮影します。
5. 確認画面下部の「共有メニューを開く」を押し、保存先を選択します。下部メニューは常に画面内に固定表示されます。
7. 動画の音声を使う場合は調整パネルで音声録音をONにし、表示されたマイク権限を許可します。

## 権限とプライバシー

カメラ・マイクはブラウザ標準APIで取得し、処理は端末内で完結します。サーバーへのアップロードは行いません。マイクは音声録音をONにして録画を開始した時だけ要求します。

## 対応環境

- iOS 16以降のSafariを主対象
- 最新のSafari / Chrome / Edge（PCでのデバッグを含む）
- WebGLが使えない場合はCanvas 2Dへ自動フォールバック

## 動画形式とSafariの制約

`canvas.captureStream()` と `MediaRecorder` の両方が利用できる場合だけ、加工済み動画を録画できます。形式は端末が実際に対応するものを `MediaRecorder.isTypeSupported()` で検出し、MP4/H.264、MP4、WebMの順で選択します。利用可能な形式がなければ写真機能のみ使えます。

iOSのバージョンによってはCanvas録画や音声との合成が制限されます。録画後の0.5x/1x/2x/5x/10xはプレビュー再生速度だけを変更し、共有する動画ファイル自体は変換しません。

## 既知の制限

- 2DフォールバックではWebGL版よりピント境界が明瞭になります。
- 高画質は端末の発熱やフレーム低下を招くため、通常は標準を推奨します。
- 録画中の画面ロック・タブ移動・着信で録画が中断される場合があります。
- 背面カメラの種類（広角・超広角など）の直接指定はブラウザ側の選択に依存します。
- 長時間動画は端末メモリを消費します。短いクリップでの利用を推奨します。
