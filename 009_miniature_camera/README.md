# Miniature Camera

iPhone Safari向けのティルトシフト風カメラです。横帯・縦帯・円形・楕円形のピント領域を残して周辺を段階的にぼかし、色補正した映像をリアルタイム表示します。撮影時は、画面に表示している加工済みCanvasそのものを写真または動画にします。

## 起動方法

ビルドは不要です。HTTPSで配信するか、開発時はリポジトリ直下でローカルサーバーを起動します。

```sh
python -m http.server 8000
```

`http://localhost:8000/009_miniature_camera/` を開いてください。カメラは安全なコンテキスト（HTTPSまたはlocalhost）でのみ利用できます。

## GitHub Pages

リポジトリの Settings → Pages で公開ブランチとルートを選択します。公開後は `https://<user>.github.io/<repository>/009_miniature_camera/` から利用できます。

## 基本操作

1. Safariでページを開き「カメラを開始」をタップしてカメラを許可します。
2. プレビューをタップするとピント位置が滑らかに移動します。1本指ドラッグでも移動できます。
3. 「ピント編集」では、2本指ピンチで幅、2本指回転で角度を変更します。「ズーム」に切り替えるとピンチはズーム操作になります。
4. 基本画面の「ミニチュア度」だけでも、ぼかし・幅・色をまとめて調整できます。
5. 写真／動画／TIME LAPSEを選び、中央の撮影ボタンを押します。
6. 確認画面下部の「共有メニューを開く」を押して保存先を選択します。下部メニューはiPhoneのセーフエリア内に固定表示されます。

## 主な機能

- 自然、標準、強調、街並み、鉄道模型、夜景、レトロ模型、トイカメラ、ソフトのプリセット
- 押している間だけ元映像を表示する「比較」ボタン
- OFF／3×3／中央十字／水平線の撮影グリッド
- 横帯／縦帯／円形／楕円形のぼかし形状
- カメラ能力を確認して使うネイティブズームと、非対応時のデジタルズーム
- 端末の許可操作を経て表示する簡易水平器
- 15fps／10fps／6fpsで描画を更新するコマ撮り風動画
- ×2／×4／×8／×16の加工済みタイムラプス生成
- 写真ライブラリからの画像読み込みと加工写真の作成
- 動画ライブラリからの加工プレビュー、および対応ブラウザでの実時間再生による加工済み動画書き出し
- LocalStorageへの設定保存と「設定を初期化」
- FPS低下時の内部処理解像度の段階的な自動調整

## タイムラプスと倍速プレビューの違い

TIME LAPSEモードは、指定倍率に応じた間隔で加工済みCanvasのフレームを実際に取得し、停止後に30fpsの短い動画として生成します。録画中は実撮影時間と完成予想時間を表示します。端末メモリを守るため、内部フレームは最大640px幅・600枚に制限しています。

撮影後の `0.5x / 1x / 2x / 5x / 10x` は「倍速プレビュー」です。再生速度だけを変更し、共有するファイル自体は変換しません。

## 権限とプライバシー

カメラ・マイク・読み込んだメディアは端末内で処理し、サーバーへアップロードしません。マイクは音声録音をONにして通常動画を録画する時だけ要求します。水平器はユーザーが「水平器を有効にする」を押した時だけ、必要に応じてDeviceOrientationの権限を要求します。権限状態自体は設定として保存しません。

## 対応環境とフォールバック

- iOS 16以降のSafariを主対象
- 最新のSafari / Chrome / Edge（PCデバッグを含む）
- WebGLが使えない場合はCanvas 2Dへ切り替え
- ネイティブズーム非対応時は1x～3xのデジタルズーム
- DeviceOrientation非対応時は水平器を無効化
- `canvas.captureStream()`、`MediaRecorder`、対応MIME形式が揃わない場合は動画・タイムラプス書き出しを無効化

動画形式は `MediaRecorder.isTypeSupported()` で確認し、MP4/H.264、MP4、WebMの順で端末が利用できるものを選択します。既存動画の加工済み書き出しは、元動画を再生しながら同じ時間をかけて録画する方式です。

## 既知の制限

- SafariのWeb Shareがファイル共有に対応しない場合、撮影結果の共有ボタンは利用できません。
- 2DフォールバックではWebGL版よりピント境界が明瞭で、色温度など一部補正が簡略化されます。
- 高画質、強いぼかし、長時間録画、タイムラプス生成は発熱やメモリ消費につながります。
- タイムラプスは停止後に動画生成時間が必要です。タブ移動や画面ロックを行わないでください。
- 録画中の画面ロック、タブ移動、着信で録画が中断される場合があります。
- 背面カメラの広角・超広角などの選択は、ブラウザが公開するズーム能力に依存します。存在しない倍率は固定表示しません。
